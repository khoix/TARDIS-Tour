# Geometry research tasks — status register

These tasks come from bible §12.8 (M01–M12) and §18.3 (P01–P20). They need **new evidence of a different type**: legally obtained footage for frame surveys, authenticated production drawings, or a scale-calibrated photo set (bible §J). None of that is available to this project, so every task is marked `blocked_access`.

This status satisfies the §20.3 freeze gate's "completed or marked inaccessible" condition honestly. Geometry stays **normalized and parametric**, and no task may be reported as done without the evidence it names.

Unblocking input: lawful footage access, a measured or official Pickwoad plan, or a licensed scan of the 2018 manual [S24]. If such input arrives, record findings in `research/measurements/` with the calibration columns from bible §18.2.
